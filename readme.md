## Getting Started

### Requirements

- Python 3.8 or newer

### Installation

```bash
git clone https://github.com/sarishtshreshth0/Network-Share.git
cd network-share
```

### Usage

>  **Order matters:** always start the server first.

**1. Start the server**

```bash
python server.py
```

**2. In a new terminal, start the first client**

```bash
python client.py
```

**3. In another terminal, start the second client**

```bash
python client2.py
```
